# 玩法說明：LINE Bot 管理網站使用指南

這份文件說明如何使用本專案的網站後台介面，方便你管理 LINE Bot 的收件對象、罐頭訊息、立即發送與固定排程。

## 進入網站後台

1. 啟動專案：

```bash
npm run dev
```

2. 開啟瀏覽器，前往：

```text
http://localhost:3000
```

3. 在「後台登入」區塊輸入 `.env` 中設定的 `ADMIN_TOKEN`，按下「儲存登入」。

> 如果你尚未設定 `ADMIN_TOKEN`，此欄位可留空（僅測試用）。

## 系統狀態面板

頁面右上會顯示系統狀態，包括：

- Web App 是否正常
- LINE Token 是否已設定
- 後台是否已開啟保護（ADMIN_TOKEN）
- 時區設定

## 立即發送

在「立即發送」區塊：

1. 從 `收件對象` 選擇要發送的群組 / 個人 / 多人聊天室。
2. 從 `罐頭訊息` 選單選擇已有的模板，或直接在 `發送內容` 欄位輸入手動內容。
3. 選擇是否 `靜音通知`。
4. 按下「立即發送」，系統會立即透過 LINE Bot 發送訊息。

## 新增收件對象

在「新增收件對象」區塊：

- `類型`：選擇 `group`、`user` 或 `room`
- `名稱`：可填寫群組名稱、使用者名稱或你想辨識的備註名稱
- `LINE ID`：填入真正的 `groupId`、`userId` 或 `roomId`
- `備註`：可留空

按下「新增/更新收件對象」後，對象會顯示在「收件對象列表」中。

> 你也可以透過 LINE 群組或私訊 BOT 來自動記錄 `groupId` / `userId`，系統會自動產生對象。

## 新增罐頭訊息

在「新增罐頭訊息」區塊：

- 輸入模板 `標題`
- 輸入模板 `內容`

範例可使用變數：

```text
{收件人名稱}
{LINE_ID}
{日期}
{時間}
```

按下「新增罐頭訊息」後，模板會儲存並出現在「罐頭訊息列表」中。

## 建立固定排程

在「固定排程」區塊：

1. 輸入 `排程名稱`
2. 選擇要使用的 `罐頭訊息`，或留空自行輸入內容。
3. 選擇要發送的 `收件對象`。
4. 設定 `發送時間`，若不想手動寫 cron，可使用「星期」勾選自動產生。
5. 如果要手動填寫 cron，請輸入例如：`0 13 * * 6`（每週六 13:00）。
6. 選擇是否啟用排程、是否靜音通知。
7. 按下「新增排程」。

新增後，排程會顯示在「排程列表」中，你可以：

- `停用` / `啟用` 排程
- `刪除` 排程

## 查看資料與紀錄

### 收件對象列表

顯示目前已儲存的收件對象：

- 名稱
- 類型
- LINE ID
- 備註
- 編輯／刪除操作

### 罐頭訊息列表

顯示目前所有模板：

- 標題
- 內容
- 編輯／刪除操作

### 排程列表

顯示已建立的排程：

- 排程名稱
- cron 設定
- 罐頭訊息名稱
- 收件對象
- 啟用狀態
- 停用／刪除操作

### 訊息 / Webhook 紀錄

「發送 / Webhook / LINE Bot 紀錄」區塊會顯示過去執行結果與錯誤訊息，方便你追蹤：

- 發送狀態
- 時間
- 來源類型
- 錯誤或成功訊息

## 進階使用建議

- 若要發送給指定家長，請先新增 `userId` 收件對象，再用立即發送或定時排程發送。
- 若要分批發送給群組，請先新增 `groupId` 收件對象。
- 建議先建立常用的 `罐頭訊息` 模板，再在立即發送、排程中重複使用。
- 若要測試內容，可先使用 `靜音通知`，避免打擾使用者。

## 常見問題

### 1. 為什麼看不到收件對象？

請確認你已新增收件對象，或已讓 BOT 加入 LINE 群組／私訊 BOT 並完成綁定。若系統尚未讀取，請重新整理頁面。

### 2. 為什麼訊息沒發送？

請確認 `.env` 中的 `LINE_CHANNEL_ACCESS_TOKEN`、`LINE_CHANNEL_SECRET` 是否正確，且後台保護 `ADMIN_TOKEN` 是否設定正確。

### 3. 為什麼排程沒跑？

請確認專案正在執行中、且 `schedule` 功能在後端正常運作。若你直接關閉電腦或終端，排程將停止。
